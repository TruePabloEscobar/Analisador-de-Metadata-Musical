TRACK SCANNER - ARQUIVOS DE GIT

Coloque estes arquivos na pasta do projeto.

- .gitignore
- Verificar_Open_Source.ps1
- Enviar_para_GitHub.bat
- Puxar_do_GitHub.bat

PRIMEIRO ENVIO:
Execute Enviar_para_GitHub.bat.

O envio:
- verifica segredos, caminhos pessoais e arquivos locais comuns;
- respeita o .gitignore;
- preserva/sincroniza o LICENSE existente no GitHub;
- usa e-mail GitHub noreply no repositorio local se nenhum e-mail local estiver configurado;
- mostra o que sera commitado antes do push;
- envia para main.

PARA PUXAR:
Execute Puxar_do_GitHub.bat.

Se a pasta do projeto nao existir, ele clona o repositorio.
Se houver mudancas locais nao commitadas, ele cancela para nao sobrescrever trabalho.
